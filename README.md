## ✨ Features

- **Text → ASCII** — 5 fonts, 12 charsets, live preview
- **Image → ASCII** — Colored output, brightness/contrast control
- **Live Camera** — Real-time ASCII from your phone
- **Sprite Editor** — Draw your own animations frame by frame
- **Animation Export** — Record as WebM video
- **Custom Colors** — 6 themes + picker + 12 palettes
- **Bilingual** — فارسی and English
- **Social Export** — Instagram 1080×1080, Telegram 512×512
- **CRT Glitch** — Retro scanline effect
- **Local Gallery** — Keeps last 12 creations
- **6 Presets** — Instagram, Telegram, Matrix, Neon, Paper, Minimal
- **Zero Dependencies** — One HTML file, no build
