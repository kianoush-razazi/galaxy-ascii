🚀 Quick Start

Option 1: Use Online

Open Galaxy in your browser:

"🌌 Open Galaxy Live Demo" (https://kianoush-razazi.github.io/galaxy-ascii)

Option 2: Run Locally

Clone the repository:

git clone https://github.com/kianoush-razazi/galaxy-ascii.git
cd galaxy-ascii

Open "index.html" in a modern browser.

That's it! No build step, no package installation, and no external dependencies are required.

📖 How to Use

📝 Text Mode

1. Open the Text tab.
2. Enter your desired text (up to 14 characters).
3. Choose a font: Vazir, Bebas, Serif, Script, or Mono.
4. Select a character set and color theme.
5. Preview your artwork, then save or copy it.

🖼️ Image Mode

1. Open the Image tab.
2. Upload a photo from your device.
3. Adjust the grid size to control character density.
4. Enable Colored mode for colored output.
5. Export your creation as PNG, SVG, or a social media image.

📷 Camera Mode

1. Open the Camera tab.
2. Grant camera permission when prompted.
3. Tap the capture button to take a picture.
4. Enable Live Mode for real-time ASCII conversion, if available.
5. Save your result.

🎨 Animation Mode

1. Open the Animation tab.

2. Select characters from the drawing palette:
   
   "█ ▓ ▒ ● ◆ ★ + ×"

3. Draw on the grid using your mouse or touchscreen.

4. Tap + to create another frame.

5. Repeat to build your animation.

6. Press Play to preview your work.

7. Use Record to export your animation as a WebM video.

🛠️ Tech Stack

Galaxy is built with lightweight browser technologies.

- HTML5 — Application structure.
- CSS3 — Responsive styling and custom design system.
- Vanilla JavaScript — Application logic without a framework.
- Canvas API — Image processing and artwork rendering.
- MediaRecorder API — Animation recording.
- LocalStorage — Local persistence for settings and saved creations.

Architecture: A single HTML application with no build tools or third-party runtime dependencies.

🎯 Design Principles

- Zero dependencies: No frameworks, external CDNs, or package installation.
- Mobile first: Designed for touchscreens and smaller displays.
- Privacy focused: Artwork processing happens locally in the browser.
- Accessible: High-contrast visuals and bilingual support.
- Responsive: Designed to work across different screen sizes.
- Lightweight: A single HTML application with client-side rendering.

🔒 Privacy

Galaxy is designed to run locally in your browser.

- No application server is required for core features.
- Images and artwork can be processed on your device.
- LocalStorage can retain settings and creations in your browser.
- Camera access requires your permission.
- The hosted version requires an internet connection to load initially; local usage is possible without an internet connection after obtaining the project files.

Your browser's own storage and permission settings determine how local data is retained and when camera access is available.
