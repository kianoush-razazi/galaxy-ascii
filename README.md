📱 How to Use

📝 Text Mode

1. Open the Text tab
2. Type your word (up to 14 chars)
3. Pick a font · charset · theme
4. Save or copy

🖼 Image Mode

1. Switch to Image
2. Upload a photo
3. Adjust Grid — lower = bigger, clearer characters
4. Toggle Colored for pixel-accurate output
5. Export as PNG / SVG / IG / TG

📷 Camera Mode

1. Switch to Camera
2. Grant permission
3. Tap to capture, or enable Live Mode
4. Save

✦ Animation Mode

1. Open Animation
2. Pick a character — █ ▓ ▒ ● ◆ ★ + ×
3. Draw on the grid with your finger
4. Tap + for the next frame
5. Repeat 4–8 frames
6. Play to preview · Record to save WebM
